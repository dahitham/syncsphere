# SyncSphere 🚀

SyncSphere is a full-stack task management and team collaboration platform built using the MERN stack.

It helps teams manage:
- tasks
- projects
- notifications
- collaboration
- productivity

---

# Features ✨

## Authentication
- User Signup
- User Login
- JWT Authentication
- Password Hashing using bcrypt

## Task Management
- Create Tasks
- Update Tasks
- Delete Tasks
- Track Task Status

## Team Collaboration
- Team Members
- Shared Workspace
- Notifications

## Dashboard
- Productivity Dashboard
- Task Overview
- Team Activity

## Backend Features
- REST API
- MongoDB Atlas Integration
- Express Middleware
- Rate Limiting
- Error Handling
- CORS Security
